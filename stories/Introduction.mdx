# Plynx UI

A modern React dashboard UI kit with a flexible theming system. 15+ components, 3 curated themes, full TypeScript support.

## Installation

```bash
npm install @plynx/ui
```

## Setup

Wrap your app in `ThemeProvider` and import the stylesheet:

```tsx
// main.tsx
import { ThemeProvider, baseTheme } from '@plynx/ui'
import '@plynx/ui/styles'

ReactDOM.createRoot(document.getElementById('root')!).render(
  <ThemeProvider initialTheme={baseTheme} themes={[baseTheme]}>
    <App />
  </ThemeProvider>
)
```

## Using Components

```tsx
import { Button, Card, Input } from '@plynx/ui'

function ProfileForm() {
  return (
    <Card header="Edit Profile">
      <div className="flex flex-col gap-4">
        <Input label="Full name" placeholder="Alex Smith" />
        <Input label="Email" type="email" placeholder="alex@example.com" />
        <Button>Save changes</Button>
      </div>
    </Card>
  )
}
```

## Theme Switching

Plynx UI ships with three themes. Switch using `setTheme` from `useTheme`:

```tsx
import { useTheme } from '@plynx/ui'

function ThemeToggle() {
  const { setTheme, currentTheme } = useTheme()
  return (
    <button onClick={() => setTheme(currentTheme.name === 'dark' ? 'base' : 'dark')}>
      Toggle dark mode
    </button>
  )
}
```
